# Issue tracker: GitHub

Issues and specs live at https://github.com/saeed-mosavat/doneward.
Use the `gh` CLI for issue operations.

Infer the repository from the Git remote. Until a remote is configured,
pass `--repo saeed-mosavat/doneward` explicitly.

When asked to publish to the issue tracker, create a GitHub issue.
When asked to fetch a ticket, read its body, labels, and comments.

PRs as a request surface: no.
