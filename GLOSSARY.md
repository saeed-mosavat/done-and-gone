# Doneward

A personal task board for organizing work through customizable columns.

## Language

**Board**:
An ordered collection of columns containing the user's cards.
_Avoid_: Workspace, project

**Column**:
A named, ordered stage of work within a board. Each column contains an ordered collection of cards.
_Avoid_: Lane, status

**Card**:
A task with a required title and an optional plain-text description, belonging to exactly one column.
_Avoid_: Issue, ticket

**Welcome card**:
The sample card included in Todo on a new board.
_Avoid_: Placeholder card
